# نظام إدارة العملاء CRM - التجارة الإلكترونية

نظام CRM متكامل باللغة العربية لإدارة التجارة الإلكترونية مع واجهة مستخدم حديثة وسهلة الاستخدام.

## ✨ المميزات

### 📊 لوحة التحكم
- إحصائيات شاملة عن المبيعات والعملاء
- أحدث الطلبات في الوقت الفعلي
- المنتجات الأكثر مبيعاً
- تنبيهات المخزون التلقائية

### 👥 إدارة العملاء
- عرض قائمة كاملة بالعملاء
- بحث متقدم بالاسم، البريد الإلكتروني، أو رقم الهاتف
- تقييم العملاء بالنجوم
- إحصائيات لكل عميل (عدد الطلبات، إجمالي الإنفاق)
- إضافة وتعديل وحذف العملاء

### 📦 إدارة الطلبات
- متابعة حالة الطلبات (قيد المعالجة، قيد التوصيل، مكتمل، ملغي)
- نظام بحث وتصفية متقدم
- عرض تفاصيل كل طلب
- إحصائيات الطلبات حسب الحالة
- تصدير التقارير

### 🏪 إدارة المنتجات
- كتالوج شامل للمنتجات
- تصنيف المنتجات حسب الفئات
- متابعة المخزون التلقائية
- تنبيهات عند نفاذ المنتجات
- إحصائيات المبيعات والإيرادات لكل منتج
- مؤشرات الاتجاه (ارتفاع/انخفاض المبيعات)

### 📈 التحليلات والتقارير
- رسوم بيانية تفاعلية للمبيعات
- تحليل الإيرادات حسب الفئة
- الأداء الشهري
- المنتجات الأكثر ربحية
- مقاييس العملاء والاحتفاظ
- معدلات التحويل

## 🛠️ التقنيات المستخدمة

- **React 18** - مكتبة بناء واجهات المستخدم
- **TypeScript** - للكتابة الآمنة والموثوقة
- **Tailwind CSS** - للتصميم العصري والمتجاوب
- **Vite** - أداة البناء السريعة
- **Lucide React** - أيقونات حديثة
- **Recharts** - رسوم بيانية تفاعلية
- **Firebase** - قاعدة بيانات ومصادقة (اختياري)

## 🚀 التشغيل

```bash
# تثبيت المكتبات
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build
```

## 🔥 إعداد Firebase (اختياري)

النظام يعمل بوضعين:

### 1. وضع التجربة (Demo Mode) 📝
- يعمل مباشرة بدون إعداد
- بيانات تجريبية محلية
- مثالي للتجربة والتطوير

### 2. وضع Firebase 🔥
- قاعدة بيانات حقيقية
- مصادقة المستخدمين
- تحديثات فورية

لإعداد Firebase، اتبع الدليل التفصيلي في: **[FIREBASE_SETUP.md](./FIREBASE_SETUP.md)**

### الخطوات السريعة:
1. أنشئ مشروع في [Firebase Console](https://console.firebase.google.com/)
2. فعّل Authentication و Firestore
3. انسخ بيانات الإعداد إلى `src/firebase/config.ts`
4. أعد تشغيل التطبيق

يمكنك التبديل بين الوضعين باستخدام زر 🔥/📝 في واجهة التطبيق!
